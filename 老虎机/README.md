# Forager 抽奖辅助（老虎机）

Forager 游戏三区抽奖辅助工具。通过屏幕截图 + OpenCV 彩色模板匹配识别滚动的奖品，在目标物品出现时自动按 E 停止转盘。

流程：观测奖品池 → 按物品权重自动选目标 → 逐区（1→2→3）识别并按 E 停止。

## 目录结构

```
老虎机/
├── 配置.py             # 全部参数配置（区域、阈值、权重、分组等）
├── requirements.txt    # 依赖列表
├── README.md           # 本说明文档
├── 启动识别.bat         # 启动识别模式（无 Web 服务器）
└── 调整顺序.bat         # 启动物品排序编辑器（Web 界面）
└── src/                # 源代码和资源文件夹
    ├── main.py             # 主程序（CLI 模式入口）
    ├── engine.py           # 核心识别引擎（多区域截屏 + 模板匹配 + 状态机）
    ├── slot_machine.py     # 抽奖状态机（观测→决策→逐区停止）
    ├── gui.py              # 桌面图形界面（Tkinter）
    ├── web_serve.py        # Web 界面后端（本地 HTTP 服务 + 引擎控制）
    ├── overlay.py          # 屏幕悬浮窗（显示当前/目标物品图标）
    ├── select_region.py    # 手动框选识别区域工具
    ├── resources/          # 物品模板图片（按分类子目录存放）
    │   ├── 考古/ 加工/ 卷轴/ 药剂/ 食物/ 矿物/ 种子/ 其他/
    ├── web/                # Web 前端页面
    └── libs/               # 离线依赖包（wheel 文件）
```

## 环境要求

- Python 3.10+
- Windows 系统

安装 Python 依赖：

```
双击"安装依赖.bat"
```

依赖列表：`opencv-python`、`numpy`、`mss`、`pynput`

## 配置

直接编辑 `配置.py` 文件修改配置，保存后重启程序生效。

所有配置项都在 `配置.py` 文件中，每个配置都有详细的注释说明。

## 使用

### 启动方式

| 方式 | 命令 / 操作 | 说明 |
|------|------------|------|
| 识别模式 | 双击 `启动识别.bat` | 纯引擎模式，无 Web 界面 |
| 排序编辑 | 双击 `调整顺序.bat` | 打开浏览器编辑物品权重和分组 |
| Web 界面 | `python src\web_serve.py` | 完整 Web 控制界面 |
| 图形界面 | `python src\gui.py` | Tkinter 桌面界面 |
| CLI 模式 | `python src\main.py` | 命令行界面 |

### 热键

| 热键 | 功能 |
|------|------|
| F8   | 启动/暂停识别 |
| F9   | 退出程序 |
| Ctrl+Alt+D | 启动（Web 模式） |
| Ctrl+Alt+A | 停止（Web 模式） |
| Ctrl+Alt+F | 全自动（Web 模式） |
