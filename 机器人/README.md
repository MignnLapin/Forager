# Forager 抽奖助手（机器人）

Forager 游戏的抽奖辅助工具。通过屏幕截图 + OCR 悬停识别奖品文字，在"终结"出现时自动点击祭坛，进入全自动循环，直到心降到阈值自动停止。

全自动流程：保存退出 → 开始游戏 → 进入抽奖 → 悬停识别 OCR 文字 → 点击「终结」→ 循环。

## 目录结构

```
机器人/
├── 配置.py             # 主要配置文件（直接在此修改）
├── requirements.txt    # 依赖列表
├── README.md           # 本说明文档
└── src/                # 源代码和资源文件夹
    ├── hover_recognize.py   # 主程序入口
    ├── resources/           # 模板图片（各奖品图标、爱心等）
    └── libs/                # 离线依赖包（wheel 文件）
```

## 环境要求

- Python 3.10+
- Windows 系统

安装 Python 依赖：

```
双击"安装依赖.bat"
```

依赖列表：`opencv-python`、`numpy`、`mss`

## 配置

直接编辑 `配置.py` 文件修改配置，保存后重启程序生效。

主要配置项都在 `配置.py` 文件中，每个配置都有详细的注释说明。

## 使用

双击 `启动助手.bat` 启动程序，屏幕左下角出现悬浮窗。

| 热键 | 功能 |
|------|------|
| F8   | 启动/停止全自动模式 |

- 悬浮窗右上角有 ✕ 按钮可关闭
- 全自动完成后会播放提示音
