# Forager 钓鱼辅助

Forager 游戏钓鱼辅助工具。通过屏幕截图 + OpenCV 彩色滑窗匹配识别「捕获提示」出现，自动连点鼠标左键完成收竿。

## 目录结构

```
钓鱼/
├── 配置.py             # 参数配置（阈值、点击次数、区域坐标等）
├── requirements.txt    # 依赖列表
├── README.md           # 本说明文档
├── 开始识别.bat         # 一键启动
└── src/                # 源代码和资源文件夹
    ├── fish.py             # 主程序入口
    ├── select_region.py    # 手动框选监控区域工具
    ├── resources/          # 捕获提示模板图片（Y/G 两种）
    └── libs/               # 离线依赖包（wheel 文件）
```

## 环境要求

- Python 3.10+
- Windows 系统

安装 Python 依赖：

```
双击"安装依赖.bat"
```

依赖列表：`opencv-python`、`numpy`、`mss`、`pynput`

## 配置

直接编辑 `配置.py` 文件修改配置，保存后重启程序生效。

所有配置项都在 `配置.py` 文件中，每个配置都有详细的注释说明。

## 使用

双击 `开始识别.bat` 启动程序。

### 热键

| 热键 | 功能 |
|------|------|
| F5   | 框选/重新选择监控区域 |
| F8   | 开始/暂停识别 |
| F9   | 退出程序 |

首次使用需先按 F5 框选鱼竿浮标附近「捕获提示」出现的区域，框选后自动保存。之后按 F8 开始识别，程序会持续监控该区域，检测到提示后自动连点收竿。
